Pizza Ordering Program

Overview

This Python coursework project simulates a pizza ordering process.

Features

* Collects customer information and pizza selections.
* Validates user input.
* Calculates order costs based on pizza size and quantity.
* Includes carryout and delivery options.
* Displays an order countdown and completion message.

Technologies

* Python

Background

Created as part of CIS110 programming coursework at Strayer University.
